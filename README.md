# Hotel Emerald Inn — Customized Website

A responsive hotel landing page customized with the property details supplied by the hotel contact.

## Files
- `index.html` — complete standalone website.

## Preview
Open `index.html` in a modern browser.

## Included
- Luxury-inspired forest green and gold visual style
- Tagline: “Stay in comfort”
- Address, phone, WhatsApp, email and Google Maps link
- Room details: 2 non-AC rooms at ₹1,300/night and 16 Deluxe AC rooms at ₹1,600/night
- Listed facilities: free Wi-Fi, private parking (underground and front), room service, air conditioning, 24-hour front desk, lift/elevator and laundry service
- Check-in at 12 PM and check-out at 11 AM
- Booking.com, Goibibo and MakeMyTrip links
- Direct WhatsApp booking enquiry
- Responsive mobile layout

## Before publishing
- Replace the decorative room placeholders with actual hotel photos when available.
- Confirm that room prices, amenities and contact details are current.
- Review OTA booking links. The supplied Goibibo and MakeMyTrip URLs include specific dates and may need updating.
- The booking form sends an enquiry via WhatsApp; it does not check live inventory or confirm reservations.
- A domain name was not supplied, so no domain is configured.

## Deploy
Upload `index.html` to Vercel, Netlify, or another static web host. For Vercel, you can import a GitHub repository containing this file or deploy the folder.
